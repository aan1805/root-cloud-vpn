Как это работает

Celery каждые 15 минут запрашивает статистику у Fornex API для всех серверов с заданным VPS ID. Данные (CPU, RAM, трафик) сохраняются в БД и отображаются на дашборде.

Ожидаемый формат ответа API:
{"cpu": 12.5, "mem": 45.1, "net": {"in": 1234, "out": 5678}}

VPS ID серверов

Укажите ID VPS в панели Fornex для каждого сервера. Найти можно в адресной строке: fornex.com/vds/12345/
